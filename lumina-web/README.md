# LUMINA Web

The web app of [LUMINA](../README.md) — an Instagram-style Nostr client built around kind 20 picture posts (NIP-68).

React 19 · Vite · Tailwind 4 · shadcn/ui · Nostrify · TanStack Query.

```bash
npm install
npm run dev    # http://localhost:8080
npm run test   # type check, lint, tests and production build
```

Documentation: [`docs/`](docs/README.md) — architecture, features, the Nostr protocol contract, design system,
security and development notes. Agent rules: [`AGENTS.md`](AGENTS.md); product spec: [`../AGENTS.md`](../AGENTS.md).
